# MILESTONE-02 — Enterprise Inventory Specification

## Goal

Define the full MikroTik Manager Enterprise Inventory scope before building backend modules.

This milestone adds the official inventory map for:

- System
- Interfaces
- IP
- Routing
- Firewall
- Services
- Wireless
- QoS
- Automation
- Containers
- Monitoring
- Backup Center
- Configuration Explorer

This is a documentation milestone. Source implementation starts after approval.
