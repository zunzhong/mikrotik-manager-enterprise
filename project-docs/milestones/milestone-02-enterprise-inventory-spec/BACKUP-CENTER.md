# Backup Center

## Goal

Backup Center is a dedicated enterprise module, separate from Inventory.

## Features

```txt
Backup Center
├── Manual Backup
├── Scheduled Backup
├── Binary Backup (.backup)
├── Text Export (.rsc)
├── Version History
├── Restore
├── Diff Between Backups
├── Compare Router Configs
├── Download Backup
├── Upload Backup
└── External Storage
    ├── Local Disk
    ├── S3
    ├── Google Drive
    ├── SMB
    └── NAS
```

## Future Capabilities

- Encrypted backup storage
- Per-device backup retention policy
- Automatic backup before risky changes
- Configuration rollback
- Backup integrity verification
