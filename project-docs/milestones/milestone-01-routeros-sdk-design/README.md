# MILESTONE-01 — RouterOS SDK Design

## Goal

Design the architecture of `@mme/routeros-core` before implementing the advanced SDK.

This milestone defines:

- Public SDK API
- Internal module architecture
- RouterOS API protocol pipeline
- Connection state machine
- Authentication flow
- Command execution flow
- Streaming/listen flow
- Error model
- Test strategy
- Implementation roadmap

This package is design-only. Source implementation starts after approval of this milestone.
